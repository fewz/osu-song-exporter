osu! Song Exporter

Export semua lagu dari folder osu! menjadi library musik terstruktur berdasarkan artist. Mendukung unicode title, incremental export, multithread processing, playlist otomatis, export cover/background, dan database persistent.

Python 3.9+
Multithread
Unicode Support
Playlist Generator
Incremental Export

Features

Artist Folder Structure Semua lagu otomatis dipisah berdasarkan artist.
Unicode Support Menggunakan TitleUnicode dan ArtistUnicode dari beatmap osu.
Incremental Export Lagu yang sudah pernah diexport otomatis di-skip.
JSON Database Menyimpan histori export ke exported_songs.json.
Playlist Generator Membuat playlist global dan playlist per artist.
Background Export Export cover/background image dari beatmap.
Multithread Processing Export jauh lebih cepat pada SSD dan multicore CPU.
Copy / Move Mode Bisa copy file atau move file langsung.

Project Structure

project_folder
├── main.py
├── config.py
├── exported_songs.json

Requirements

  • Python 3.9 atau lebih baru
  • Tidak membutuhkan library tambahan

How It Works

  1. Scan semua folder beatmap osu
  2. Membaca metadata dari file .osu
  3. Mengambil artist, title, audio, dan background
  4. Export lagu ke folder artist
  5. Menyimpan histori export ke JSON database
  6. Membuat playlist otomatis

Running The Script

python main.py

Testing Mode

Untuk testing cepat: 

LIMIT = 10

Untuk export semua lagu: 

LIMIT = None

Configuration

Semua konfigurasi berada di file config.py 

# Folder Songs osu
OSU_SONGS_FOLDER = r"D:\Games\osu!\Songs"

# Folder output
EXPORT_FOLDER = r"D:\Exported_Osu"

# True = copy
# False = move
COPY_MODE = True

# Export background image
EXPORT_BACKGROUND = True

# Generate playlist
GENERATE_PLAYLIST = True

# Rebuild database
REFRESH_DATABASE = False

# None = export semua lagu
LIMIT = 10

# Multithread workers
MAX_WORKERS = 8

Database System

Script menggunakan file: 

exported_songs.json

untuk menyimpan lagu yang sudah pernah diexport.

Duplicate Detection

Duplicate dicek menggunakan: 

unicode_artist + unicode_title

Example JSON

{
  "yoasobi::アイドル": {
    "artist": "YOASOBI",
    "title": "アイドル",
    "audio": "D:\\Exported_Osu\\YOASOBI\\アイドル.mp3"
  }
}

Refresh Database

Untuk rebuild database dan export ulang semua lagu: 

REFRESH_DATABASE = True
Mode Description
False Incremental export dan skip lagu lama
True Rebuild database dan export ulang semua lagu

Performance Tips

Untuk SSD dan multicore CPU: 

MAX_WORKERS = 16

Export speed akan meningkat signifikan pada library besar.
